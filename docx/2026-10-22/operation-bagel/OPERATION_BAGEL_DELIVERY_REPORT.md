## 一、 交付背景与问题解决

在先前版本中，用户反映无法使用指令查询或更新「贝果计划」战绩。经系统性分析：
1. **米游社底层接口**：米哈游战绩网关已有完整的总览与明细 API（代号 `zenkov_abstract_info` 与 `zenkov_detail`），且 `ZZZ-Plugin` 底层早已完成对接与卡片渲染；
2. **实际失效根因**：
   - 指令正则枚举了“迷宫诡域”、“搜打撤”、“绝科夫”等，但**遗漏了官方正式活动标题与玩家最常用的“贝果”和“贝果计划”**；
   - QQBot 快捷指令层（`zzzShortcuts.js`）未收录贝果与迷宫路由，导致用户输入 `/贝果` 或 `/贝果战绩` 时被未知指令拦截器拦截报错；
   - 指令不支持 `(更新|刷新)?` 容错前缀，导致玩家习惯性发送 `/更新贝果战绩` 时无法匹配。

本次交付针对以上痛点完成了端到端彻底改造与上线。

- **前缀增强**：扩展统一前缀正则常量 `const P = "[\\/#＃%％]?"`，全面兼容斜杠 `/`、井号 `#`、百分号 `%` 以及纯词输入；
- **新增贝果战绩详情路由**：
  ```javascript
  else if (new RegExp(`^${P}(更新|刷新)?(贝果|贝果计划|迷宫|迷宫诡域|搜打撤|绝科夫)(战绩|记录|详情|回顾)$`, "i").test(msg)) {
    target = "#绝区零贝果战绩"
  }
  ```
