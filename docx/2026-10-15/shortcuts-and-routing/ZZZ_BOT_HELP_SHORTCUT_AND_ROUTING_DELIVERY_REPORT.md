## 1. 核心改进方案与实现细节

### 1.1 帮助快捷指令拦截映射
在 `plugins/example/zzzShortcuts.js` 的前置管道 `accept(e)`（优先级 -1000）中补充最高优先级规则：
```javascript
// 0. 帮助 / 菜单 / 功能 / 指令说明：/帮助, /help, /菜单, /功能, /指令, 帮助, help
if (new RegExp(`^${P}(帮助|help|菜单|功能|说明|指令)$`, "i").test(msg)) {
  target = "#绝区零帮助"
}
```
- **消歧保护**：直接将用户的 `/帮助`、`帮助`、`/help` 归一化重写为原生 `#绝区零帮助`，打上 `e.game = "zzz"` 标识，彻底终结了此前穿透至原神 `miao-plugin/apps/help.js` 并输出原神帮助的问题。

### 1.2 非法 / 未识别快捷指令的防穿透阻断机制
为避免任何拼写错误、非法或未注册的快捷指令（如 `/原神深渊`、`/未知指令`、`/test` 等）穿透到底层原神插件或系统模块，在 `accept(e)` 末尾增加了斜杠输入严格兜底校验：
```javascript
// 8. 非法 / 未识别快捷指令统一拦截并报错，彻底防止错误指令穿透至原神等其他模块
if (this.isSlashInput(e)) {
  const raw = typeof e.raw_message === "string" && e.raw_message ? e.raw_message : (e.original_msg || e.msg || "")
  const cleaned = raw.replace(/<@!?\d+>/g, "").replace(/\[CQ:[^\]]*\]/g, "").trim()
  const cmd = cleaned.replace(/^[/／#＃]+/, "").trim().split(/\s+/)[0]
  const tip = cmd ? `没有快捷指令“/${cmd}”，可发送 /帮助 查看支持的快捷指令。` : "没有这条快捷指令，可发送 /帮助 查看支持的快捷指令。"
  await e.reply(tip, true)
  return "return"
}
```
- **关键机制**：返回 `"return"` 会直接触发 TRSS-Yunzai 内核 `lib/plugins/loader.js` 的 `if (res === "return") return`，**立即终止整个消息流的分发，后续所有插件规则都不会再被执行**，形成零穿透的绝对防御。
